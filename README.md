# Studio Noir — Salão de Beleza

Landing page estática (HTML/CSS/JS) para salão de beleza: seções de serviços, sobre, depoimentos e contato/agendamento.

## Rodando localmente

Abra o `index.html` diretamente no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```
